Die elektromagnetische Welle

So sieht die Welle weit weg vom Dipol aus (Fernfeld). Rot ist das E-Feld, blau das B-Feld. Dreh die Welle und schau sie dir von allen Seiten an.

Empfang mit dem Lämpchen

Der Sendedipol steht senkrecht. Dreh den Empfangsdipol und beobachte das Lämpchen.

Eine Familie, viele Namen

Schieb durch das ganze Spektrum: von Wellen, die länger sind als ein Dorf, bis zu Wellen, die kleiner sind als ein Atom.

Vom Ton zur Welle

Ein Ton hat nur ein paar hundert Schwingungen pro Sekunde. Er wird auf eine schnelle Trägerwelle „aufgeladen“. Das heißt Modulation.

Der Empfänger: Sender einstellen

Die Antenne empfängt alle Sender gleichzeitig. Ein Schwingkreis (L = 0,10 µH) mit Drehkondensator sucht sich einen heraus. Dreh am Kondensator.

Ein Bild per Funk

Ein Bild besteht aus Pixeln. Jedes Pixel ist eine Zahl, jede Zahl besteht aus Bits (0 oder 1). Die Bits reiten auf der Trägerwelle: Träger an = 1, Träger aus = 0.

Tippe Pixel an. Darunter siehst du, was die Antenne sendet.

Hier kommt ein Bild an. Lies Zeile für Zeile ab: Träger da = schwarzes Pixel. Tippe die Pixel an und prüfe.
