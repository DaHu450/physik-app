Physik-App

Bevor es losgeht, holst du dir die App auf den Home-Bildschirm:

  1. Tippe oben in Safari auf Teilen (□↑).
  2. Wähle „Zum Home-Bildschirm" und tippe auf Hinzufügen.
  3. Schließ Safari und öffne die App über das neue Physik-Symbol.
Deinen Code gibst du erst in der App ein, nicht hier.

Gib deinen 8-stelligen Code von deiner Lehrerin ein. Das geht nur einmal. Danach ist die App fest mit deinem Code verbunden.

Ist das wirklich dein Code?

Wenn du bestätigst, kannst du den Code nie mehr ändern. Alles, was du abgibst, wird diesem Code zugeordnet.

Tipp: Leg die App auf den Home-Bildschirm (Safari → Teilen → „Zum Home-Bildschirm"). Dann läuft sie auch ohne Internet.

Abgeben

Was willst du abgeben?

So geht's:
  1. Tippe auf Datei erstellen.
  2. Im Teilen-Menü wählst du Nextcloud.
  3. Lade die Datei in den Abgabe-Ordner, den deine Lehrerin mit dir geteilt hat.
Klappt das Teilen nicht, wird die Datei in „Dateien" gespeichert. Von dort kannst du sie in Nextcloud hochladen.

Mehr

Diese App ist fest mit deinem Code verbunden. Mit der Sicherungsdatei kannst du deinen Stand auf ein neues Tablet mitnehmen (nur mit demselben Code).
